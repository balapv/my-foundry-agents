# Synthetic data

Everything in this folder is fictional and generated by `generate_data.py`. The data is deterministic: seed `20260514`, no network access, and no randomness at runtime.

```powershell
python data/generate_data.py           # regenerate all JSON files
python data/generate_data.py --check   # validate committed files without rewriting them
```

## Files

| File | Contents |
|---|---|
| `customers.json` | 30 Contoso Air Altitude members: name, contact info (`example.com` and `555` numbers), loyalty number and tier, home airport |
| `reservations.json` | 60 reservations: confirmation code, primary customer, status, cabin, fare type, passengers and segments |
| `flights.json` | 150 scheduled flight instances (12 days ago to 7 days ahead) with seat availability by cabin |
| `flight-status.json` | Operational status for every flight instance: on time, delayed, cancelled, landed, plus disruption details |
| `fault-injection.json` | Simulated outages the tools API returns for evaluation scenario D3 |

Each file has a `metadata` block that records the generator, the seed and the anchor date.

## Dates and rebasing

The data is stored relative to the **anchor date 2026-05-14**, which is "today" inside the files. The tools API shifts every date in its responses by `(demo today - anchor)`, so Alex Johnson's flight is always cancelled **tomorrow**, whatever day you run the demo.

- `DEMO_TODAY=YYYY-MM-DD` pins the demo date, which is useful for rehearsals and tests.
- `DEMO_TIME=HH:MM` pins the time of day in `DEMO_TIMEZONE`. It decides which of today's flights have already departed and caps `lastUpdated` timestamps so they are never in the future.
- Without them, the API uses the current date and time in `DEMO_TIMEZONE` (default `America/Los_Angeles`).

The files on disk never change at runtime, so resetting the demo never requires regenerating data.

Flight `CT999` never exists (scenario D2). Confirmation codes for non-hero customers are generated. Look them up with the reservation tool, or in `reservations.json`.

Background disruptions on other flights make the system look realistic. They are kept off the scenario routes and dates so each scenario search returns exactly the intended options. Seattle also has unrelated departures on the hero day (for example to SFO, LAX, DEN and DFW), so SEA→JFK is not the only activity at Alex's home airport.

## Fault injection

Set `DISABLE_FAULT_INJECTION=true` on the tools API to turn off the simulated outage.

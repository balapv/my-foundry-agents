About this workspace

  • The agent is configured and inspected in the Microsoft Foundry portal (or created from code with the same definition).
  • This workspace invokes that same Foundry-managed agent through the Foundry SDK, attaching the claim’s documents and photographs so it can review the complete claim.
  • The workspace presents claim facts and evidence. The review and recommendation come from the agent; decisions stay with the adjuster.
